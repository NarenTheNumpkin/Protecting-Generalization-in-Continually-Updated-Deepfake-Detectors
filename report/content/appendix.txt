Two settings were chosen by registered rules on development data. For GPL, the watermark generator was trained with learning rates $10^{-4}$ and $10^{-3}$ on stream S1 with the development splits. The rule was to keep the candidates whose mean gain is at least half that of sequential fine-tuning and to take the one with the higher FaceShifter probe AUROC, or, if neither qualified, the one with the higher gain. With $10^{-4}$ the generator barely learned (gain 0.01), with $10^{-3}$ it reached a gain of 1.53 against 1.58 for sequential fine-tuning, so $10^{-3}$ was chosen. For the matched-plasticity experiment, the setting of each competitor whose mean development gain was closest to that of GA+LwF (1.03) was selected, with ties broken toward the more regularized setting. The development gains were 1.29, 0.94, 0.71 and 0.43 for LwF with $\lambda_l$ of 1, 2, 4 and 10; 1.58, 1.09 and 0.54 for sequential fine-tuning with learning rates $10^{-4}$, $3\cdot10^{-5}$ and $10^{-5}$; and 1.32, 1.09 and 0.85 for GA with $\lambda$ of 1, 3 and 10. The rule therefore chose $\lambda_l=2$, a learning rate of $3\cdot10^{-5}$ and $\lambda=3$.

The settings of GPL that its paper does not report were fixed before any GPL run. The watermark generator consists of three $3\times3$ convolutional layers with 8, 16 and 32 channels, each followed by $2\times2$ max pooling, and a final $1\times1$ convolution with a sigmoid that produces a mask at one eighth of the input resolution, which is upsampled and multiplies a learned watermark shared by all samples. The watermark is initialized at zero, so that the initial model equals the base detector, and the temperature of the hyperbolic contrastive loss is 0.1. The conflicting gradient component is removed completely, unit-length features are mapped into the Poincaré ball with the exponential map at the origin, and the 25 cluster centers per class are computed with spherical k-means on eight frames of each of 100 genuine and 100 manipulated FaceForensics++ fitting videos.

@appendix SOURCE CODE OF THE UPDATE STEP {app:code}

The listing below is the central part of the training function in `experiments/stream.py`, slightly condensed for printing: the branch of the GPL re-implementation, the prototype-memory variants and the logging are omitted, and the repeated cosine-drift expression is written as a helper function. It shows how every method shares the same loop and differs only in the term added to the GenD loss. In the code, `realkd` denotes genuine-sample alignment (GA) and `realkd_lwf` the combination GA+LwF; label 0 is genuine and label 1 manipulated.

@code
def embed(model, x):
    """Returns (logits, unit-norm features)."""
    f = model.feature_extractor(x)
    return model.model(f), F.normalize(f.float(), dim=1)

def gend_loss(logits, z, y, ce=1.0, unif=0.5, align=0.1):
    return (ce * F.cross_entropy(logits.float(), y)
            + unif * uniformity(z) + align * alignment(z, y))

def cos_drift(z, z_p, sel):          # mean of 1 - cos over selected samples
    return (1 - (z[sel] * z_p.float()[sel]).sum(1)).mean()

def train_task(model, prev, train_videos, args, fisher=None, anchor=None):
    params = [p for p in model.parameters() if p.requires_grad]
    opt = torch.optim.Adam(params, lr=args.lr)
    ds = FrameSet(frames(train_videos),
                  model.feature_extractor.preprocess, True)
    dl = DataLoader(ds, batch_size=args.batch, shuffle=True,
                    drop_last=True)
    total = args.epochs * len(dl)
    sched = torch.optim.lr_scheduler.LambdaLR(
        opt, lambda s: 0.5 * (1 + math.cos(math.pi * s / total)))
    m = args.method
    for ep in range(args.epochs):
        model.train()
        for x, y, _ in dl:
            x, y = x.cuda(), y.cuda()
            with torch.autocast("cuda", dtype=torch.bfloat16):
                logits, z = embed(model, x)
                if m not in ("seq", "ewc"):      # frozen previous model
                    with torch.no_grad():
                        logits_p, z_p = embed(prev, x)
            loss = gend_loss(logits, z, y)
            if m in ("lwf", "realkd_lwf", "featkd_lwf"):   # logits
                T = 2.0
                kd = F.kl_div(F.log_softmax(logits.float() / T, 1),
                              F.softmax(logits_p.float() / T, 1),
                              reduction="batchmean") * T * T
                loss = loss + args.lam * kd
            if m in ("featkd", "featkd_lwf"):              # all faces
                loss = loss + args.lam * cos_drift(z, z_p, slice(None))
            if m in ("realkd", "realkd_lwf") and (y == 0).any():
                loss = loss + args.lam * cos_drift(z, z_p, y == 0)  # GA
            if m == "fakekd" and (y == 1).any():           # fakes only
                loss = loss + args.lam * cos_drift(z, z_p, y == 1)
            if m == "randkd" and (y == 0).any():  # random, same count
                n = int((y == 0).sum())
                sel = torch.randperm(len(y), device=y.device)[:n]
                loss = loss + args.lam * cos_drift(z, z_p, sel)
            if m == "ewc":                                 # Fisher
                pen = sum((fisher[n] * (p - anchor[n]) ** 2).sum()
                          for n, p in model.named_parameters()
                          if p.requires_grad)
                loss = loss + args.lam * pen
            opt.zero_grad(set_to_none=True)
            loss.backward()
            opt.step()
            sched.step()
@endcode
